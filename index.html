🚀 STEP-BY-STEP GITHUB PAGES DEPLOYMENT GUIDE

Follow these 5 simple steps to host and publish your live web app for free.

STEPS 1 & 2

1. Create Repository & Index File

  1. Log into your account at GitHub.com.
  2. Click the "+" icon in the upper right and select New repository.
  3. Name your repository singularity-game.
  4. Select Public, check Add a README file, and click Create repository.
  5. Click Add file ➔ Create new file, name it exactly index.html.
  6. Paste all the single-file code from this editor into the box and click Commit changes...
STEPS 3, 4 & 5

2. Enable Pages & Access Site

  1. In your repository, click ⚙️ Settings tab at top.
  2. On the left sidebar, click Pages under Code and automation.
  3. Under Build and deployment ➔ Source, select Deploy from a branch.
  4. Under Branch, select main (or master) and folder /(root), then click Save.
  5. Wait 1–2 minutes, then refresh. GitHub will display your live site link:
https://<your-github-username>.github.io/singularity-game/
